همسفر — ورود ساده با انتخاب نام

اعضا:
۱. لینک سایت را باز می‌کنند.
۲. نام تلگرام خود را انتخاب می‌کنند.
۳. دکمه «ورود با نام انتخاب‌شده» را می‌زنند.
۴. اطلاعات عمومی خود را تکمیل و ذخیره می‌کنند.
هیچ کد یا رمز جداگانه‌ای برای اعضا لازم نیست.

مدیر:
در صفحه ورود، بخش «ورود مدیر سفر» را باز کند و رمز مدیر را وارد کند.
اگر با انتخاب نام وارد شده، اول «خروج از حساب» را بزند.
انتخاب نام Farhad Leader دسترسی مدیریت ایجاد نمی‌کند.
دستیارها اجازه ویرایش مشخصات سایر افراد را ندارند.
توجه: انتخاب نام، تأیید هویت نیست. هر دارنده لینک می‌تواند نام دیگری را انتخاب کند؛ اطلاعات حساس وارد نشود.

به‌روزرسانی GitHub:
فایل ZIP را باز کنید. محتویات آن، شامل پوشه api و tests، را در ریشه مخزن فعلی آپلود کنید.
فایل‌های قبلی هم‌نام را جایگزین کنید. خود ZIP را به‌جای سورس آپلود نکنید.

راه‌اندازی روی Vercel:
۱. پروژه hamsafar-esfahak را باز کنید.
۲. در Storage یا Marketplace، یک پایگاه داده Postgres مثل Neon بسازید و به Production پروژه وصل کنید.
   اگر انتخاب طرح یا هزینه‌ای نمایش داده شد، همان‌جا بررسی و انتخاب کنید؛ این بسته سرویسی خریداری نمی‌کند.
۳. در Settings > Environment Variables مطمئن شوید DATABASE_URL یا POSTGRES_URL ساخته شده است.
   این مقدار نشانی محرمانه اتصال دیتابیس است؛ آن را در چت یا GitHub قرار ندهید.
۴. یک متغیر دیگر به نام HAMSAFAR_ADMIN_CODE بسازید و مقدارش را یک رمز تصادفی خصوصی با حداقل ۱۶ نویسه بگذارید.
   این رمز ورود مدیر روی سایت خواهد بود. نام متغیر را دقیقاً با همین حروف انگلیسی بنویسید.
۵. Framework Preset را Other بگذارید. اگر قبلاً Build Command و Output Directory را دستی تعیین کرده‌اید،
   آن تنظیمات دستی را پاک کنید تا تنظیمات vercel.json استفاده شود. فرمان ساخت python build_static.py و خروجی public است.
۶. از Deployments گزینه Redeploy را بزنید تا فایل‌ها و متغیرهای جدید اعمال شوند.
۷. آدرس https://hamsafar-esfahak.vercel.app/api/state را باز کنید.
   پیام JSON «برای دیدن اطلاعات همسفرها وارد شوید» قبل از ورود طبیعی است و یعنی API به دیتابیس رسیده است.
   خطای ۴۰۴ یعنی بخش api منتشر نشده؛ پیام JSON با وضعیت ۵۰۳ یعنی تنظیمات یا ارتباط پایگاه داده هنوز آماده نیست.
۸. به صفحه اصلی برگردید؛ نام خود را انتخاب و اطلاعات را ذخیره کنید. از دستگاه دوم نمایش تغییرات را بررسی کنید.

اطلاعات تکمیلی:
رمز قدیمی اجرای محلی خودکار به Vercel منتقل نمی‌شود؛ رمز آنلاین همان HAMSAFAR_ADMIN_CODE است که شما تعیین می‌کنید.
اطلاعات موجود در رایانه در این بسته نیست و خودکار به دیتابیس آنلاین منتقل نمی‌شود.
این تغییر هنوز در مخزن یا سایت شما منتشر نشده و اتصال واقعی دیتابیس آنلاین باید پس از تنظیمات آزمایش شود.
برای اجرای محلی همچنان START.bat کار می‌کند؛ اطلاعات آن در پوشه private روی همان رایانه می‌ماند.
در اجرای محلی جدید، رمز مدیر داخل private/access-codes.txt نوشته می‌شود. اعضا به آن فایل نیاز ندارند.
